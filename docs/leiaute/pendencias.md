# Pendências do leiaute S-1.3

Tudo que o código usa sem confirmação no leiaute, no XSD, no MOS ou numa Nota Técnica.
No código, cada um destes pontos leva `// CONFERIR NO LEIAUTE S-1.3: <campo>`.
Ao confirmar, mova a linha para "Confirmados", com a fonte e a data.
